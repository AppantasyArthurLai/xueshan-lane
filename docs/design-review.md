# 雪隧王道 — 設計評審紀錄

方向：精密汽車儀表的質感，加上隧道意象（光帶、透視、速度感）。動態要克制，並遵守 `prefers-reduced-motion`；只做深色版；不用 emoji；不載入外部字體或 CDN；顏色對比達 WCAG AA。

截圖：`node scripts/shoot.js docs/screens/round{N}`。腳本會啟動 mock 伺服器，用 Chromium 模擬 iPhone 14、iPhone SE 和桌機 1440x900 截圖（這台機器缺系統函式庫，WebKit 無法執行）。除了預設的 mock 狀態，另外用固定資料拍兩張：`*-rec.png` 是綠色建議狀態，`*-stale.png` 是資料過期狀態。說明頁存成 `explain-*.png`。

評分採 Awwwards 四項標準（Design / Usability / Creativity / Content），每項 1–10 分，盡量誠實給分。

## Round 1 — 基準（改版前）

`docs/screens/round1/`

| Design | Usability | Creativity | Content |
|:-:|:-:|:-:|:-:|
| 5 | 7 | 3 | 6 |

評語：
- 結構是對的：建議、左右兩塊、提示、時間、說明連結都在，1 秒內看得懂。但整體觀感是「預設的深色模板」，沒有自己的視覺語言。
- 主建議區用大面積亮綠（#16a34a）配白字，副標小字的對比只有 3.3:1，未達 AA；灰色狀態則是一塊平的石板灰，看起來很廉價。
- 層級不清楚：「前方車輛約 35 台（推估）」的數字、單位、標籤混在同一行置中；iPhone SE 上「台」和「（推估）」各自斷行，「模擬資料」也被拆成兩行。
- 方向切換用黃色實心按鈕，搶走了主建議的注意力。
- 桌機版只是把手機版放寬到 720px 置中，下方留一大片空白。
- 說明頁是一長串文字，公式區塊用等寬字體顯示中文，很難讀。
- **BUG（已重現）**：「請勿開車時操作」的禁止圖示是內嵌 SVG，沒有 `width`/`height` 屬性，尺寸完全靠 `.ico` 這條 CSS 規則。iPhone Safari 拿到新版 HTML、卻沿用快取裡的舊版 `style.css`（舊版沒有 `.ico` 規則），SVG 就會被撐成整頁寬：iPhone 14 寬度下是 366×366px 的白色圓環，正好出現在資料時間那行下方。用舊 CSS 搭配新 HTML 可以穩定重現。

## Round 2 — 第一版重設計

`docs/screens/round2/`

| Design | Usability | Creativity | Content |
|:-:|:-:|:-:|:-:|
| 7 | 7 | 7 | 7 |

主要改動：
- 建立設計 token：4px 間距系統（`--s-1`…`--s-8`）、圓角三級、三層灰階文字（ink / ink-2 / ink-3）；綠色只用於建議、灰色表示差不多、琥珀色用於警告與過期。
- 字體：CJK 依序用系統的 PingFang TC / Noto Sans TC / Noto Sans CJK TC；數字改用 SF Pro Display 等無襯線字體，搭配 `tabular-nums`，讓數字、單位、標籤成為三個清楚的層級。
- 主建議區改成「隧道口」：用透視 SVG 畫出逐漸縮小的拱圈光帶、路面和黃色中線，兩條車道上有流動光點（純 SVG dash 動畫，車速越快，光點流得越快）。
- 車道卡片改成儀表風格：大號速度數字、0–100 刻度條、數據列表（標籤靠左、數字靠右）。
- 方向切換改成帶滑動指示塊的中性白色分段控制。
- 資料時間前加一顆 live 脈動點，過期時轉成琥珀色。
- 所有 SVG 補上 `width`/`height` 屬性，CSS 與 JS 的網址加上版本號（`?v=3`），從根本修掉白色圓環。

評語：
- 質感明顯提升，隧道意象讓人一眼就認得出主題。
- iPhone 14 上「差不多」被拆成「差不 / 多」；「兩線」單獨占一行，標題斷得很難看。
- iPhone SE 上「內側 / 外側」被擠到第二行，因為隱藏的「建議」chip 仍然占著寬度。
- 背景用 `background-attachment: fixed` 疊漸層，全頁截圖中間出現一道色帶接縫。
- 桌機版主建議區上半部是空的，資料時間孤零零浮在右側，版面顯得鬆散。

主要改動：

- 桌機版改為「主建議滿版 → 左右車道 → 進隧道提示 + 資料時間」的分層；車道卡片在桌機上分成「儀表 | 數據」兩欄。
- 隧道頂部加上一排燈具光帶。
- 截圖腳本新增綠色建議狀態與過期狀態（過期時主建議外框和光點轉為琥珀色，警示列為實心琥珀）。

評語：
- 綠色建議狀態很好：深綠底配白字，對比足夠；右線光點發綠光，和右側卡片的綠框、chip 互相呼應，1 秒就能讀懂。
- iPhone SE 的過期截圖上，「前方車輛約」斷成兩行。
- 進隧道提示仍是一整段文字，最關鍵的資訊（從哪個交流道、多遠）沒有被凸顯出來。
- 隧道圖沒標出哪條是左線、哪條是右線，看圖和看卡片要自己對應。
- 桌機版的資料時間卡片內容太少、太小。

`docs/screens/round4/`

| Design | Usability | Creativity | Content |
|:-:|:-:|:-:|:-:|

主要改動：
- 進隧道提示改成路線小圖：`坪林交流道 —— 約 1 km —— 隧道口`，虛線光點朝隧道口流動。完整句子留在下方作為補充說明（e2e 仍驗證「隧道內禁止變換車道」這段文字）。
- 隧道路面標上「左」「右」，建議的那一側標字會轉綠，和下方卡片直接對應。
- 數據標籤設 `nowrap`，SE 縮小字級後「前方車輛約」不再斷行。
- 桌機版的資料時間改成 28px 等寬數字，有時鐘的感覺；隧道圖放大。
- 對比檢查：最淡的文字（#8691a0）放在各種底色上都 ≥ 4.6:1；原本「推估」小字因為加了 opacity 只有 3.9:1，已移除 opacity，改為 5.4:1。
- 數字更新時會從舊值滾動到新值（ease-out，最長 0.9 秒）。設定減少動態時直接換成新值，流動光點、脈動點、刻度條動畫也全部關閉。

評語：
- 手機版三種狀態（差不多、建議、過期）層級一致，主建議最大最亮，數字比單位重，標籤最淡，第一眼就落在答案上。
- 隧道光帶、車道光點、路線虛線三者共用同一套「光點流向隧道」的語彙，動畫克制，而且有實際意義（光點流速對應車速）。
- 說明頁加入章節編號（01–08）、公式卡片、色票，閱讀節奏好很多。
- 仍可再進步的地方：桌機版主建議區中段留白偏多；隧道圖在 SE 上的「左 / 右」標字很小（純裝飾，`aria-hidden`）。

四項都 ≥ 8，且已完成 3 輪以上，結束迭代。

## BUG 修正：iPhone 上的白色半圓 / 圓環

- 原因：內嵌 SVG 沒有內建尺寸，只靠 CSS 控制大小。只要樣式表沒套用（例如 Safari 快取了舊版 `style.css`），SVG 就會被撐到容器寬度。
- 修正：
  1. 所有內嵌 SVG 都加上 `width`/`height` 屬性。
  2. CSS 加上 `svg { max-width: 100% }` 作為保底。
  3. `style.css?v=3`、`app.js?v=3` 加上版本號，避免新 HTML 配舊 CSS。
- 測試：
  - e2e「SVGs are bounded and nothing oversized below data time」跑兩種情境：正常情況，以及樣式表回傳空內容（模擬快取或樣式失效）。驗證圖示類 SVG ≤ 40px、其他 SVG 尺寸有上限，且資料時間以下沒有任何元素高於 120px。拿舊版 HTML 來跑會失敗（Received: 374），拿新版跑會通過。
  - 說明頁另有一個 SVG 尺寸 e2e 測試。
  - 單元測試檢查每個 `<svg>` 都有 `width`/`height` 屬性，且 CSS/JS 網址都帶版本號。
